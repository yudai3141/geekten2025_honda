# Share Motti Desktop

Share Mottiのデスクトップアプリケーション（メインアプリ + マスコット）

## 📁 プロジェクト構造

```
desktop-mascot/
├── src/
│   ├── main/          # Electronメインプロセス
│   │   └── main.ts
│   ├── preload/       # Preloadスクリプト
│   │   └── preload.ts
│   └── renderer/      # レンダラープロセス（React）
│       ├── main.tsx
│       ├── App.tsx
│       ├── App.css
│       └── index.css
├── public/
│   └── assets/        # 3Dモデルなど
├── index.html
├── package.json
├── tsconfig.json
└── vite.config.ts
```

## 🚀 セットアップ

### 1. 依存関係のインストール

```bash
cd desktop-mascot
npm install
```

### 2. Reactの依存関係をインストール（peerDependencies）

```bash
npm install react react-dom three @react-three/fiber @react-three/drei
```

### 3. 開発サーバーの起動

```bash
npm run electron:dev
```

## 🔗 既存システムとの関係

このプロジェクトは既存の`frontend`をデスクトップアプリ化します。
- 既存のフロントエンドアプリ（http://localhost:5173）をElectronウィンドウで表示
- 3Dモデルは`frontend/src/assets/`からコピーして使用
- マスコットキャラクターをクリックするとメインアプリウィンドウが開く

## 🎯 2つのウィンドウ

### メインアプリウィンドウ
- 既存のShare Mottiアプリ全体を表示
- 通常のアプリケーションウィンドウ
- サイズ: 1200x800

### マスコットウィンドウ
- デスクトップに常駐する3Dキャラクター
- 透明・枠なし・常に最前面
- クリックスルー機能付き
- サイズ: 300x400

## 🎮 使い方

### 起動方法

#### 1. フロントエンドの開発サーバーを起動
```bash
cd ../frontend
npm run dev
```

#### 2. Electronアプリを起動
別のターミナルで：
```bash
cd desktop-mascot
npm run electron:dev
```

### 起動時の動作
- ✨ **マスコットキャラクター**がデスクトップに表示される
- メインアプリウィンドウは**最初は表示されない**
- デスクトップに可愛いキャラクターが棲みつく！

### 操作方法
- **👆 マスコットをクリック**: メインアプリウィンドウを開く
- **☰ アイコンをドラッグ**: マスコットを移動
- **🖱️ システムトレイをクリック**: メインアプリを表示
- **🖱️ システムトレイ右クリック**: メニューから各種操作

### システムトレイメニュー
- 🏠 メインアプリ: メインウィンドウを表示
- 👻 マスコットを表示/非表示: マスコットの表示切り替え
- ❌ 終了: アプリを終了
